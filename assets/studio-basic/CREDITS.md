## Delivery

100 files / 110,402,304 bytes. The manifest's `url` fields record immutable upstream provenance. The application downloads the mirrored files from `assets/studio-basic/samples/{id}.{extension}`, relative to the page; extension is the upstream URL's `.flac` or `.wav`. The served manifest is identical to the embedded manifest. The version and cache keys remain `studio-basic-2-piano` because the sample bytes have not changed.

Installation is explicit. STANDARD needs no sample download. Browser storage may be cleared by the browser or user; STUDIO can be reinstalled.
